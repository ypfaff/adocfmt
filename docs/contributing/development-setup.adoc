= Development setup

This page sets up the tools you need to work on adocfmt and shows the commands that build, test and lint it.

== Install the tools

https://mise.jdx.dev[mise] installs the tools in the versions that link:../../mise.toml[`mise.toml`] pins.
Install mise and activate it in your shell, as its https://mise.jdx.dev/getting-started.html[getting started guide] describes.
Then run this once in your clone:

[source,shell]
----
mise install
mise run setup
----

`mise run setup` installs the Asciidoctor gem that the tests run with and the Git hooks that link:../../lefthook.yml[`lefthook.yml`] defines.

== Build

[source,shell]
----
go build ./...
----

Build the IntelliJ plugin and check it against IntelliJ IDEA 2026.2 and the latest release:

[source,shell]
----
intellij-plugin/gradlew --project-dir intellij-plugin build verifyPlugin
----

The first run downloads both IDEs, about 1 GB each.

[#test]
== Test

[source,shell]
----
go test ./...
----

The full run loads Asciidoctor from Ruby, so it needs the gem that `mise run setup` installs.
To run only the tests that need no Asciidoctor, add `-short`:

[source,shell]
----
go test -short ./...
----

xref:testing-strategy.adoc[The testing strategy] describes what the tests check.

TIP: After `mise run setup`, every push runs `go test ./...` first.

[#lint]
== Lint

Lint the Go code:

[source,shell]
----
golangci-lint run
----

Check the formatting of the Java code; `spotlessApply` instead of `spotlessCheck` formats it:

[source,shell]
----
intellij-plugin/gradlew --project-dir intellij-plugin spotlessCheck
----

Lint the shell scripts:

[source,shell]
----
find . -name '*.sh' -not -path './.git/*' -exec shellcheck {} +
----

Lint the GitHub workflows:

[source,shell]
----
go tool -modfile=tools/actionlint/go.mod actionlint
----

Check the formatting of the documentation:

[source,shell]
----
mise run check-docs
----

TIP: After `mise run setup`, every commit runs these linters first.

[#website]
== Build the website

The website is built from `docs/` with Hugo, which `go tool` builds from the module in link:../../tools/hugo/go.mod[`tools/hugo`].
Build it and serve it at `http://localhost:8080/adocfmt/`:

[source,shell]
----
go run ./tools/build-website --serve
----

The build downloads Pagefind, Mermaid and highlight.js in the versions that link:../../website/package-lock.json[`website/package-lock.json`] pins, so you do not need npm.
It fails when the front matter of a page does not match its title or lacks a field.

Check the links of the built website:

[source,shell]
----
go tool -modfile=tools/htmltest/go.mod htmltest --conf website/htmltest.yml
----

= Development setup

This page lists the tools you need to work on adocfmt and the commands that build, test and lint it.

== Install the tools

Go::
Version 1.27 or later, as link:../../go.mod[`go.mod`] states.
The `toolchain` line there names the release CI builds with, and an older Go downloads that release on first use.

Asciidoctor::
The release that the tests run with.
link:../../internal/corpus/corpus.go[`internal/corpus`] pins it, and link:../../tools/fetch-asciidoctor-cases/main.go[`tools/fetch-asciidoctor-cases`] prints it for you.
Install it as a Ruby gem:
+
[source,shell]
----
gem install asciidoctor --version "$(go run ./tools/fetch-asciidoctor-cases --print-version)" --no-document
----

golangci-lint::
Version 2, which reads the configuration in link:../../.golangci.yml[`.golangci.yml`].

ShellCheck::
Lints the shell scripts.

lefthook::
Runs the Git hooks defined in link:../../lefthook.yml[`lefthook.yml`].

adocfmt::
The latest release, which formats the documentation.
xref:../how-to/install.adoc[Install adocfmt] lists the ways to install it.

You do not install actionlint, which lints the GitHub workflows.
`go tool` builds it from the module in link:../../tools/actionlint/go.mod[`tools/actionlint`], at the version pinned there.

== Build

[source,shell]
----
go build ./...
----

[#test]
== Test

[source,shell]
----
go test ./...
----

The full run loads Asciidoctor from Ruby, so `ruby` has to find the gem that the `gem install` above sets up.
To run only the tests that need no Asciidoctor, add `-short`:

[source,shell]
----
go test -short ./...
----

xref:testing-strategy.adoc[The testing strategy] describes what the tests check.

TIP: With the <<git-hooks,Git hooks>> activated, every push runs `go test ./...` first.

[#lint]
== Lint

Lint the Go code:

[source,shell]
----
golangci-lint run
----

Lint the shell scripts:

[source,shell]
----
find . -name '*.sh' -not -path './.git/*' -exec shellcheck {} +
----

Lint the GitHub workflows:

[source,shell]
----
go tool -modfile=tools/actionlint/go.mod actionlint
----

Check the formatting of the documentation, leaving out the cases under `testdata`, which are meant to be unformatted:

[source,shell]
----
adocfmt --check README.adoc CONTRIBUTING.adoc CODE_OF_CONDUCT.adoc docs
----

TIP: With the <<git-hooks,Git hooks>> activated, every commit runs these linters first.

[#website]
== Build the website

The website is built from `docs/` with Hugo, which `go tool` builds from the module in link:../../tools/hugo/go.mod[`tools/hugo`].
Build it and serve it at `http://localhost:8080/adocfmt/`:

[source,shell]
----
go run ./tools/build-website --serve
----

The build downloads Pagefind, Mermaid and highlight.js in the versions that link:../../website/package-lock.json[`website/package-lock.json`] pins, so you do not need npm.
It fails when the front matter of a page does not match its title or lacks a field.

Check the links of the built website:

[source,shell]
----
go tool -modfile=tools/htmltest/go.mod htmltest --conf website/htmltest.yml
----

[#git-hooks]
== Activate the Git hooks

Run this once in your clone:

[source,shell]
----
lefthook install
----

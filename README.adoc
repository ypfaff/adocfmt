= adocfmt

An opinionated AsciiDoc formatter in Go.

Early work in progress: one formatting rule so far, which removes the trailing whitespace of every line.
What carries it is the block scanner, the printer it feeds, and the link:docs/testing-strategy.adoc[testing strategy] every rule has to satisfy.

== Development

[source,shell]
----
go build ./...
go test ./...          # needs Asciidoctor on the PATH
go test -short ./...   # skips whatever needs Asciidoctor
golangci-lint run
----

Run `lefthook install` once to activate the Git hooks from link:lefthook.yml[`lefthook.yml`].

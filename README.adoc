= adocfmt

An opinionated AsciiDoc formatter in Go.

Early work in progress: no formatting rule is implemented yet.
What exists is the link:docs/testing-strategy.adoc[testing strategy] every rule has to satisfy.

== Development

[source,shell]
----
go build ./...
go test ./...          # needs Asciidoctor on the PATH
go test -short ./...   # skips whatever needs Asciidoctor
golangci-lint run
----

Run `lefthook install` once to activate the Git hooks from link:lefthook.yml[`lefthook.yml`].

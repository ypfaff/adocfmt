= adocfmt

An opinionated AsciiDoc® formatter in Go.

Early work in progress.
See link:docs/rules.adoc[the formatting rules] for what it changes today.
It is built from a block scanner, the printer it feeds, and a link:docs/testing-strategy.adoc[testing strategy] that every rule has to satisfy.

== Development

[source,shell]
----
go build ./...
go test ./...          # needs Asciidoctor on the PATH
go test -short ./...   # skips whatever needs Asciidoctor
golangci-lint run
----

Run `lefthook install` once to activate the Git hooks from link:lefthook.yml[`lefthook.yml`].

## Before you start

**MANDATORY**: read and follow these before making changes:

- @CONTRIBUTING.adoc: conventions, code style.
- @README.adoc: what this repository is.
- `docs/decision-records/`: why things are built the way they are; read the relevant record when a choice is unclear.
  For a non-obvious new choice, ask the author whether to add a record rather than creating one yourself.
